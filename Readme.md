# JK BMS Config · v0.1.1

Статичний двомовний конфігуратор батареї **EVE MB31 LiFePO₄ 314 Ah**, **JK-B2A8S-30P** та **AXIOMA ISMPPT-BF-DOU-GW-4200**.

## Локальний запуск

Потрібен Python 3. З кореня репозиторію:

```powershell
.\Start-Local.cmd
```

Або без PowerShell-сценарію:

```powershell
python -m http.server 8080 --bind 127.0.0.1 --directory site
```

Відкрийте **http://localhost:8080**. Зупинка — `Ctrl+C`. Можна також двічі клацнути `Start-Local.cmd` у Провіднику. Цей запуск не потребує зміни PowerShell Execution Policy. Якщо `.ps1` заблоковано системою, використовуйте `.cmd` або пряму команду Python вище. Для іншого порту замініть `8080` у прямій команді Python. Не відкривайте `index.html` через `file://`: JavaScript modules та PWA потребують HTTP(S). Локальний сервер доступний лише на цьому комп’ютері. Тести та build для запуску не потрібні; зовнішніх залежностей сайту немає.

## Можливості

- Збірка 8S1P для AXIOMA; 4S і 7S показують лише BMS та явне попередження про несумісність інвертора.
- Вибір цілей SOC: нижня 5–40%, верхня 60–100%, крок 5%. Пресети «Ресурс», «Баланс», «Резерв».
- Миттєвий перерахунок номінальної доступної енергії й робочих напруг.
- Таблиці BMS та інвертора: англійські назви зі скриншотів, український переклад, значення, джерело та пояснення.
- Пошук по назвах і поясненнях; друк / PDF **поточної вкладки з поточним фільтром**. Для всіх параметрів очистьте пошук та надрукуйте кожну вкладку окремо.
- Українська й англійська, темна та світла тема. У `localStorage` зберігаються тільки `jk-language` і `jk-theme`. Батарея, SOC та пошук не зберігаються.
- PWA: власні PNG-іконки 192/512, SVG favicon, локальний кеш усіх файлів застосунку. Жодних CDN, аналітики, зовнішніх шрифтів або API-запитів. Зовнішні посилання відкриваються лише за дією користувача.

## Межі рекомендацій

Це довідник для ручного налаштування, без підключення до обладнання. **Точне SOC-вікно за напругою LiFePO₄ забезпечити неможливо.** У режимі User інвертор не використовує SOC-поля. Програма 13 повертає навантаження на батарею, а не припиняє заряд на верхній цілі SOC. CAN/RS485 та назва протоколу не гарантують сумісності саме цих ревізій пристроїв.

Робочі профілі у `site/js/model.js` — прозорі інженерні припущення, а не виміряна SOC-крива MB31 чи рекомендація виробника для певних %. Перевірте результат за лічильником заряду та реальними умовами. Збільшення нижньої цілі SOC може не змінювати поріг переходу на мережу: програма 12 обмежена 25.5 В і кроком 0.5 В. За часткових циклів SOC BMS може дрейфувати.

Захисти BMS відокремлені від щоденних порогів інвертора і не перераховуються за SOC. Струми — початкові орієнтири за відповідних температур; переріз кабелю, запобіжник, монтаж, температура та стан комірок можуть вимагати нижчих значень. Ліміт інвертора 160 А обмежує доступну AC-потужність. Параметри без достатньо визначеної семантики в наданій документації позначені для звірки прошивки чи вимірювання. Не копіюйте заводські значення зі скриншотів автоматично.

## Офлайн та встановлення

Перший візит потребує з’єднання з локальним або майбутнім HTTPS-сервером. Дочекайтеся завантаження, потім відкрийте сторінку повторно для контролю service worker. Після успішного кешування застосунок може відкриватися без з’єднання. Зовнішні посилання офлайн недоступні. Приватний режим, очищення кешу або заборона сховища можуть прибрати офлайн-копію.

У Chromium використайте кнопку «Встановити», коли браузер запропонує встановлення, або меню браузера. В iOS Safari — «Поділитися» → «На початковий екран». На сервері потрібен HTTPS; виняток — localhost. У новій версії підвищуйте назву кешу у `sw.js` та всі відображення версії. Новий service worker активується після закриття попередніх вкладок.

## Структура

```text
site/                  # ТІЛЬКИ цей каталог переноситься на вебсервер
  index.html
  styles.css
  js/model.js          # чистий розрахунок і робочі профілі
  js/settings.js       # рекомендації та пояснення
  js/i18n.js           # переклад оболонки й методика
  js/app.js            # UI та керування станом
  assets/              # логотип та PWA-іконки
  sw.js
  manifest.webmanifest
.Документація/          # опис, методика, статус і план
doc/                   # локальні авторські матеріали; ігноруються Git
```

Джерела: надані EVE MB31 PBRI-MB31-D06-01 A, JK v19.0.1, AXIOMA ISMPPT-BF v1.2 і скриншоти JK BMS / iSolar. PDF та скриншоти не копіюються у `site/`. Публічний каталог протоколів для подальшої звірки: [JIKONG BMS Download](https://jikongbms.com/download/).

## Майбутнє розгортання

Публікація відкладена до локальної перевірки власником. Погоджений напрям: копіювання **вмісту `site/`** на сервер через Samba, окремий статичний HTTP-сервер і наявний Cloudflare Tunnel. Не обслуговуйте корінь репозиторію: `.git`, `doc` та службові файли не мають бути доступні через HTTP.

Потрібно окремо визначити Samba-шлях, вебсервер, локальний порт і правило Tunnel. Побажання щодо адреси: `jk-bms_config.iuid.cc`; перед налаштуванням перевірити підтримку `_` у hostname вашим DNS/TLS/Tunnel. Для звичайного вебхоста надійніший варіант без `_`, наприклад `jk-bms-config.iuid.cc`; остаточну назву узгодити перед публікацією.
